# Contributing to @webcoder/ui

These components are open; the platform is not (see
`docs/DECISION-OPEN-SOURCE.md` in the platform repo). Contributions are
welcome under the platform's quality gates — the same bar applies here:

- 100% coverage for every new module (statements + branches),
- zero lint warnings,
- every user-visible string ships in all 30 locale catalogs,
- a component is only added after it has stabilised in the platform.

No self-host support: issues about deploying the platform itself will be
closed.
